📖 Guide

✋ Non-AI (Bina API Key)

  1. Step 1: Style, Aspect Ratio aur Output Mode chunein, phir Characters banayein (Naam, DNA, Location).
  2. Step 2: Audio Mode aur Mood chunein. Kahani aur Hook khud likh sakte hain.
  3. Step 3: "➕ Scene Add Karein" dabayein. Action mein + @Name chips se character lagayein, Speaker dropdown se bolne wala chunein, Camera angle aur Duration check karein.
  4. Story Type, Narrator Voice aur Target clip time chunein. "👁️ Clean View" se poora project saaf-suthre read-only roop mein dekh sakte hain, aur "✏️ Edit Mode" se wapas aa sakte hain.
  5. Aakhir mein Step 3 ke neeche wale khanon (Style, har Scene, Agent Instruction, Character Sheet) mein se "📋 Copy" karein (har scene ka "🎥 Copy Flow Prompt" sirf Google Flow ke liye ek paragraph deta hai), ya "📋 Copy Complete Package" / "⬇️ Download .TXT" dabayein.

🪄 AI Mode (Gemini API Key)

  1. Upar Settings mein apni free Gemini API Key save karein (Google AI Studio se milti hai).
  2. Step 2 mein Story Length chunein, phir "✨ Story Generate" dabayein.
  3. Jahan "🪄 AI Help" ho (Character DNA, Location, Kahani, Hook, Scene) wahan dabayein, AI khud likh dega. Kahani ke liye "🧠 Story Audit" (rai aur score) aur "🔍 Logic Check" (masail ki list + theek ki hui kahani ka preview, Apply aap ki marzi se) bhi hain.
  4. Step 3 mein "✨ Auto-Generate Scenes from Story" se saare scenes ek saath ban jate hain, aur "➕ Auto-Generate: Purane Scenes Ke Baad Jorein" se lambi kahani ke agle scenes bhi jor sakte hain.
